# cognevance_Projectresponsiveportio

Responsive Portfolio Website
A responsive personal portfolio with a working contact form. Visitors send a message from the website, a Node.js API validates it, and MongoDB stores it.
Built for the Cognevance Technologies Full Stack Web Developer project tasks (Level 1: Easy).

Live site: YOUR_FRONTEND_URL
Live API: YOUR_BACKEND_URL/api/health
Problem statement
Developers need a professional online presence, but a static portfolio cannot collect inquiries. This project solves that with a responsive, animated portfolio plus a backend that validates and stores every message from visitors.
